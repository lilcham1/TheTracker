# TheTracker

A free Windows app that tracks your matches while you play: Dota 2, Deadlock, Counter-Strike 2, Overwatch, PUBG and Call of Duty. Live stats from Valve's own game feed, an in-game overlay for Dota 2, a review of every match, pro settings presets, your history and the meta, all in one place. It never reads game memory.

**Download:** [lilxcham.com/thetracker](https://lilxcham.com/thetracker/) · [Latest release](https://github.com/lilcham1/TheTracker/releases/latest)

The app lives in [`TheTracker/`](TheTracker/). Its [README](TheTracker/README.md) has the full feature list, where the data comes from, and how to build and test it.
